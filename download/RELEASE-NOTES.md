**RipscoutBBS 1.3.0: tray icon, Control Panel and two new games**

- **No more console window.** RipscoutBBS now runs from a **system tray icon** (the spinning wheel). Right-click it for Open Control Panel, Open Data Folder, Check for Updates and Shut Down. Hovering shows how many callers are online.
- **Control Panel**, a window on the server PC (this PC only, protected by a secret key) with tabs for:
  - Dashboard: live stats, a 14-day calls chart, and callers online with Page and Disconnect
  - Users: levels, lock, password reset, delete
  - Settings: every board setting, applied live
  - BMX News: the Newsmap feed list
  - High Scores, Updates and the live Log
- **Two new BMX Games:**
  - *Spoke Breaker*: a brick breaker played by bouncing a wheel off your handlebars.
  - *Block Drop*: falling blocks, with cleared lines collapsing via RIP copy-region.
- Starting the EXE a second time just opens the running board's Control Panel.

If you're running 1.2.0, this update installs itself the next time nobody is online. Afterward the console window goes away and the wheel icon appears in the tray.

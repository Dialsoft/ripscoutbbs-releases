**RipscoutBBS 1.4.0: Content Editor and linked Teleconference**

- **Content Editor** (Sysop Admin > Content Editor), done entirely in RIP and live:
  - **Menus:** every menu, including the main menu, is editable. Add, remove and reorder items; set each one's hotkey, icon, minimum level and the module or submenu it opens. Create submenus.
  - **Icons:** a swappable icon library, with a pixel editor in RIP. Click a color, click the grid.
  - **Backgrounds:** patterns, starfield, synthwave grid, sunset bands, dirt track, or a custom 8x8 texture, with a live preview. Choose one per menu, or a board default.
- **Linked Teleconference** (Sysop Admin > Chat Links): connect RipscoutBBS boards into one shared chat room over an encrypted, password-protected link.
  - Every caller has a **line number**: 03 for callers on this board, A07 for callers on linked board A.
  - **Private messages across boards:** click a name for a pop-up window, or type `/A07 hello` STS style.
- The Control Panel shows link status and edits the board tag and link port.

If you're running 1.3.0, this update installs itself the next time nobody is online.
